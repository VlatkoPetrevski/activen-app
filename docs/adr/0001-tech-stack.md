# ADR-0001: Технолошки стек — TypeScript модуларен монолит

- Статус: Прифатено (претпоставка, корисникот не избра експлицитно)
- Датум: 2026-11-18

## Контекст

Потребни се web апликација (спортист + тренер), подоцна мобилна, позадински sync со повеќе вендори и
богата аналитика. Тимот е мал; приоритет е квалитет и брзина на итерации.

## Одлука

- **Јазик:** TypeScript насекаде (strict), Node.js 22+.
- **Monorepo:** pnpm workspaces.
- **Web:** ~~Next.js~~ → Vite + React SPA (PWA), види ADR-0011. **Мобилна (подоцна):** Expo / React Native врз истиот API.
- **API:** NestJS (модули = граници на домени), OpenAPI спецификација.
- **База:** PostgreSQL. ORM/миграции: Drizzle или Prisma — одлука во инкремент 1.
- **Редици/worker-и:** Redis + BullMQ (sync, backfill, утрински брифинг).
- **Тестови:** Vitest (unit), вистински PostgreSQL (интеграциски; заменето од ADR-0009), Playwright (E2E).

## Алтернативи

- Python (FastAPI) backend: подобар екосистем за ML, но два јазика и дуплирање на типови.
- Микросервиси од старт: непотребна оперативна сложеност за оваа фаза.

## Последици

Еден јазик и споделени типови меѓу web, mobile и API. ML/предикции, ако станат тешки, можат да се
издвојат во посебен Python сервис подоцна без промена на domain договорите.
