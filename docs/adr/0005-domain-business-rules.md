# ADR-0005: Бизнис-правила (изведени од контекстот и одлуките на корисникот)

- Статус: Прифатено; ажурирано 2026-11-18 по одговорите на корисникот
- Датум: 2026-11-18

| Правило                      | Имплементација                                                                                                                                                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HR зона (§9)                 | Горната граница е инклузивна; вредноста припаѓа на првата зона чија горна граница не ја надминува. Децимален просек 139,4 → AeT. Еквивалентно на `IF(HR<=139;…)` во Excel.                                                                                 |
| Валидација на зони (HR-03)   | Цели bpm, без празнини/преклопувања, прва зона отворена надолу, последна отворена нагоре, уникатни имиња, боја `#RRGGBB`.                                                                                                                                  |
| Профил по датум (HR-04)      | Најновиот `effectiveFrom` ≤ датум; при ист датум победува повисока верзија; пред првиот профил се користи најстариот.                                                                                                                                      |
| „Run“ (§7)                   | `Run`, `TrailRun`, `VirtualRun`.                                                                                                                                                                                                                           |
| Поврзување план (§7)         | Ист локален датум → единствен Run → најдолг Run (тај: порано започнат). Повеќе сесии на ист ден се доделуваат по `sequence`. План со експлицитен друг спорт (пр. Ride) се поврзува со тој спорт. Рачната одлука победува и смее да покажува на друг датум. |
| Неделен збир (§10)           | Пон–Нед; растојание и време се собираат; темпо = вкупно време на трчање / вкупно растојание на трчање; HR и Relative Effort = просек од достапните вредности. Избришани активности и планови не се бројат.                                                 |
| Време за темпо               | По дифолт **elapsed** (колона G од извештајот); `moving` е опција.                                                                                                                                                                                         |
| Статус на план без активност | `rest`, `upcoming` (датум ≥ денес), `missed` (минат), `unlinked` (рачно одврзан).                                                                                                                                                                          |
