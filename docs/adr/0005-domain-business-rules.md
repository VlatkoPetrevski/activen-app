# ADR-0005: Бизнис-правила

- Статус: Прифатено; ажурирано 18.11.2026 (одговори на корисникот, Garmin терминологија — ADR-0007)
- Датум: 2026-11-18

| Правило                      | Имплементација                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Извори                       | Приоритет: Garmin → Suunto → Polar → COROS → Wahoo → Apple/Google Health → рачно → **Strava последна**. Корисникот може да го смени редоследот.                                                                                                                                                                  |
| HR зони — извор              | Се увезуваат од вендорот (`zonesFromLowerBounds`, 5 зони добиваат Garmin имиња) или се внесуваат рачно; корисникот избира кој извор важи (`zoneSourcePreference`). Ако нема ниту едно, важат Garmin зоните по % од max HR (`garminHeartRateZones`, max HR = 220 − возраст). Промена на границите → нова верзија. |
| Класификација во зона        | Горната граница е инклузивна; вредност над цел bpm (пр. 139,4 со граница 139) оди во повисоката зона.                                                                                                                                                                                                            |
| Валидација на зони           | Цели bpm, без празнини/преклопувања, прва зона отворена надолу, последна отворена нагоре, уникатни имиња (без мешање латиница/кирилица), боја `#RRGGBB`.                                                                                                                                                         |
| Профил по датум              | Најновиот `effectiveFrom` ≤ датум; при ист датум победува повисока верзија; пред првиот профил се користи најстариот.                                                                                                                                                                                            |
| Трчање                       | Garmin групата „running“: `RUNNING`, `TRAIL_RUNNING`, `TREADMILL_RUNNING`, `TRACK_RUNNING`, `VIRTUAL_RUN`. Филтри: само патно, без тредмил, без трејл (`PRESET_FILTERS`).                                                                                                                                        |
| Филтри                       | Ги менуваат прегледите, збировите и аналитиката, но **не** и поврзувањето план↔активност; план чија активност е скриена се прикажува со статус `completed_hidden`.                                                                                                                                               |
| Поврзување план              | Ист `calendarDate` → единствено трчање → најдолго трчање (тај: порано започнато). Повеќе сесии на ист ден по `sequence`. План со друг `plannedActivityType` се поврзува со таа група. Рачната одлука победува и смее да покажува на друг датум.                                                                  |
| Неделен збир                 | Пон–Нед; растојание (сите активности или според филтер) и време се собираат; темпо = вкупно време на трчање / вкупно растојание на трчање (**elapsed**); пулс = просек од достапните вредности; **Training Load се собира** (Garmin принцип), просекот е дополнителен; калории се собираат; моќност = просек.    |
| Статус на план без активност | `rest`, `upcoming`, `missed`, `unlinked`, `completed_hidden`.                                                                                                                                                                                                                                                    |
