# Задавање тренинзи: обичен текст или структура со помош на AI (предлог)

Статус: **имплементирано** (ноември 2026), одобрено од корисникот.

- Парсер: `@activen/domain` → `parseWorkout`, `parseTarget`, `flattenWorkout` (тестирано mk/en).
- Модел: `PlanEntry.structure` (`WorkoutStructure`), колона `plan_entries.structure` (миграција 0003),
  валидација `WorkoutStructureSchema` (contracts).
- API: `POST /v1/workouts/structure` → `{ structure | null }` (парсер прво, AI само ако е вклучен).
- AI: `ACTIVEN_AI_API_KEY` + `ACTIVEN_AI_MODEL` (Claude, Messages API); без нив работи само парсерот.
  До AI оди само текстот на тренингот.
- Веб: предлогот се појавува сам додека се пишува (по кратка пауза); „Прифати чекори“ = текст +
  структура, само „Зачувај“ = текстот точно како што е напишан; „Отфрли“ го крие предлогот за тој текст.
  Поставка во Профил → Планирање (`workoutSuggestions`, миграција 0004): исклучено = рачно копче
  „Структурирај“. Уредливи чекори,
  предупредување кога текстот се менува по структурирањето, резиме на чекорите во План, Планер и Денес.

Следно: цели од зоните/резултатите на спортистот за „5K темпо“; испраќање на часовник
(Garmin Training API); споредба план ↔ реализирано по интервал.

## Цел

Тренерот пишува тренинг онака како што би напишал порака, без формулари. Кога сака, текстот
се претвора во **структуриран тренинг**: загревање, повторувања, одмор, смирување, со целни
темпа или пулс. Структурата е јасна за спортистот, може да се испрати на часовник и ActiveN
потоа ја споредува со реализираното, интервал по интервал.

## Два начини, едно поле

1. **Директно (без AI)** — тренерот пишува „12 km со 6 × 1000 m на 5K темпо, 2 мин одмор“
   и зачувува. Спортистот го гледа текстот точно така. Ништо не се менува без тренерот.
2. **Структурирај (со AI, по избор)** — копче „Структурирај“ под истото поле. AI го чита
   текстот и предлага структура, прикажана како чекори:
   - Загревање 2 km · лесно (Z2)
   - 6 × 1000 m · 3:55–4:05 /km · одмор 2:00 лесно трчање
   - Смирување до 12 km · лесно

   Тренерот го прегледува предлогот: **Прифати**, **Измени** (секој чекор е мало поле)
   или **Отфрли** (останува само текстот). Ништо не се зачувува без прифаќање.

## Правила

- **Текстот на тренерот е изворот на вистината.** Структурата е додаток, никогаш замена.
  Оригиналниот текст секогаш се чува и прикажува.
- **Детерминистички парсер прво, AI потоа.** Чести шеми („N × D на темпо“, „N × M мин / M мин“,
  „загревање/смирување X km“) се препознаваат без AI: брзо, бесплатно и проверливо.
  Демото веќе ги препознава (`buildDemoLaps`: „6 × 1000 m“, „3 × 3 km“, „10 × 1 мин“).
  AI се користи само за слободен текст што парсерот не го разбира.
- **Целите доаѓаат од профилот на спортистот.** „5K темпо“ и „Z2“ се пресметуваат од неговите
  зони и резултати, а не се измислуваат. Ако нема податок, чекорот останува без цел и се означува.
- **Garmin модел.** Чекорите го следат Garmin Training API (`steps[stepOrder, intensity,
durationType, durationValue, targetType, targetValueLow/High]`, `WorkoutRepeatStep`), за да
  можат да се испратат на часовник (Garmin, Suunto, COROS; Polar нема испраќање).
- **Јазик.** Тренерот пишува на својот јазик (mk/en); структурата се прикажува на јазикот на
  спортистот.
- **Приватност.** До AI оди само текстот на тренингот и зоните/темпата на спортистот. Без имиња,
  без здравствени податоци. AI може да се исклучи по организација.

## Модел на податоци (нацрт)

```ts
interface PlannedStep {
  order: number;
  intensity: "warmup" | "active" | "recovery" | "rest" | "cooldown";
  duration: { type: "distance" | "time" | "open"; value: number | null };
  target: {
    type: "pace" | "heart_rate" | "zone" | "rpe" | "none";
    low: number | null;
    high: number | null;
  };
  note: string | null;
}
interface PlannedRepeat {
  order: number;
  repeat: number;
  steps: PlannedStep[];
}

// PlanEntry: description (текстот на тренерот) + structure: (PlannedStep | PlannedRepeat)[] | null
//            + structureSource: "parser" | "ai" | "manual"
```

## Што добиваме

- Спортистот: јасни чекори на телефон и часовник, утринско потсетување со целите.
- Тренерот: споредба план ↔ реализирано по интервал (истите `laps` од статистиката на
  активноста), „интервалите 3–6 беа 8 s побавни од целта“.
- Аналитика: исполнетост по интензитет, а не само по километри.
